## Conteúdo

A atividade aborda `Map`, `Set`, `var`, `let`, `const`, escopo e ECMAScript 6. A página inclui os enunciados, respostas detalhadas, trechos de código e exemplos interativos em JavaScript puro.

- [Abrir a página de entrega](https://uesb-academicos.github.io/PW2/entrega.html)

## Estrutura

- `index.html` — atividade web e cinco exercícios;
- `entrega.html` — identificação acadêmica e links para os documentos;
- `css/` — estilos responsivos e de impressão;
- `js/` — soluções e interações dos exemplos;
- `assets/` — imagens institucionais UESB e UAB;
- `docs/` — Word e PDF corrigidos, além do PDF original do enunciado;
- `DOCUMENTO_ENTREGA.md` — resumo da submissão;
- `PASSO_A_PASSO_WINDOWS.md` — instruções para publicação;
- `scripts/publicar_github.ps1` — script PowerShell com diretório temporário exclusivo e proteção contra alterações concorrentes.

O site é estático e pode ser hospedado diretamente pelo GitHub Pages, usando `main` e a raiz do repositório.
